# Universal Windows Troubleshooter
Bu skript sistem administratorları və IT mütəxəssisləri üçün hazırlanmış universal Windows problemləri həlledici alətdir. Proqram inzibatçı hüquqları ilə işləyir və ən çox rast gəlinən Windows problemlərini avtomatik şəkildə həll edir.

## Xüsusiyyətlər
- Şəbəkə problemlərinin avtomatik həlli
- Sistem performansının optimallaşdırılması
- Disk təmizləmə və bərpa əməliyyatları
- Windows Update problemlərinin aradan qaldırılması
- Driver problemlərinin həlli
- Sistem bərpa nöqtəsinin yaradılması

## Sistem Tələbləri
- Windows 10/11 (32-bit və ya 64-bit)
- Administrator hüquqları
- .NET Framework 4.5 və ya daha yuxarı versiya
- PowerShell 5.1 və ya daha yuxarı versiya

## Quraşdırma
1. Faylı yükləyin
2. Proqramın menyusundan istədiyiniz əməliyyatı seçin

## İstifadə Qaydası
1. Proqramı administrator kimi işə salın
2. Əsas menyudan istədiyiniz əməliyyatı seçin:
   - 1: Bütün ümumi problemlərin həlli (Tam bərpa)
   - 2: Şəbəkə problemlərinin həlli
   - 3: Sistem performansının optimallaşdırılması
   - 4: Disk təmizləmə və bərpa
   - 5: Windows Update problemlərinin həlli
   - 6: Driver problemlərinin həlli
   - 7: Sistem bərpa nöqtəsinin yaradılması
   - 8: Proqramdan çıxış

3. Seçim etdikdən sonra proqram avtomatik olaraq seçilmiş əməliyyatları yerinə yetirəcək
4. Əməliyyatlar bitdikdən sonra sisteminizi yenidən başlatmaq tövsiyə olunur


## Təhlükəsizlik Qeydləri
- Skript bəzi sistem parametrlərini dəyişir - istifadəçi riskləri öz üzərinə götürür
